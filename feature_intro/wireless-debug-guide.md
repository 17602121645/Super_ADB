# 「无线调试」连接功能介绍

> 适用版本：Super_ADB Main 2026-08-09+
> 模块位置：`Super_ADB_Main/dialogs/wireless_debug_dialog.py`
> 子模块：`lan_scanner_dialog.py` / `wifi_pair_dialog.py` / `qr_connect_page.py`

---

## 一、功能概览

把主界面「设备连接」区的「局域网扫描」与「WiFi 配对」合并成一个 **「无线调试」** 弹窗，用标签页分成三块，入口更清晰：

- **局域网扫描**：自动发现同网段已开启 ADB 的设备。
- **配对码连接**：Android 11+ 无线调试的 `adb pair` 流程，输入 IP / 配对端口 / 配对码。
- **二维码连接**：扫码识别手机弹出的配对二维码并回填；也可生成 PC 端二维码，手机扫描后由 Super_ADB 经 mDNS 自动完成 `adb pair`。

三个子页面共用一套窗口生命周期管理（关闭时统一 `cleanup()`，停掉后台线程）。

## 二、局域网扫描

**功能概述**：给一个网段，后台并发地对每个 IP 做 socket `connect` + ADB 握手校验（默认端口 **5555**），谁在线就列出 IP 和延迟，一键连接。

**它解决什么**

| 痛点 | 怎么治 |
|------|--------|
| 不知道设备 IP | 自动识别本机 IP，预填默认 `/24` 网段 |
| `adb connect` 要挨个试 | 后台 100 线程并发探测 |
| 找到 N 台要挨个连 | 「一键连接全部」批量串行连接 |
| 结果想发给同事 | 「复制所有 IP」直接进剪贴板 |

**使用流程**
1. 弹窗自动预填本机网段（多网卡/虚拟网卡也全列出），点 **「开始扫描」**。
2. 结果表列出在线设备的 IP / 延迟；点行尾「连接」或双击整行即可连接。
3. 「一键连接全部」确认后批量连接；「复制所有 IP」拿到 `ip:5555` 每行一个。

**IP 范围三种格式**（下拉框也可直接键入）：`192.168.1.0/24` / `192.168.1.1-192.168.1.254` / `192.168.1.42`。

**常见问题**

| 现象 | 排查 |
|------|------|
| 扫得很快但一台没找到 | 设备没开「无线调试」，或与你不在同一网段（VLAN 隔离） |
| 下拉框出现 `169.254.x.0/24` | 虚拟网卡（Hyper-V / Docker / WSL），直接忽略 |
| 找到但「连接」失败 | 设备授权过期，到设备上点「允许」重授权 |

## 三、配对码连接

**功能概述**：Android 11（API 30）起无线调试需先 **「配对」** 才能连调试端口。本页把 `adb pair` 和 `adb connect` 包装成 GUI：输入 IP / 配对端口 / 6 位配对码（或一键粘贴手机弹窗原文自动拆分），后台跑 `adb pair`，成功后再一键 `adb connect`（默认 5555）。

**为什么不能直接 `adb connect`**
- 配对端口（如 `38973`）只在配对过程中有效，**配对一次即过期**；
- 调试端口（如 `5555`）配对成功后才能连；
- 没配对就 connect，会报 `Pairing required` / `failed to connect`。

**使用流程**
1. 手机：设置 → 开发者选项 → 无线调试 →「使用配对码配对设备」，弹出 IP / 端口 / 配对码。
2. 电脑：在本页填入（或「📋 粘贴」自动解析），点 **「开始配对」**。
3. 配对成功后点「连接调试端口」，主窗口设备列表自动刷新。

**常见问题**

| 现象 | 排查 |
|------|------|
| 报 `Pairing required` | 没先 pair，或配对端口已过期，重新走手机弹窗 |
| 粘贴后字段没解析 | 剪贴板不是手机弹窗原文，手动填或重新复制 |
| 配对成功但连不上 5555 | 调试端口被占用/被防火墙拦，确认设备无线调试仍开启 |

## 四、二维码连接

**功能概述**：双向工具——
- **📷 扫码（手机 → PC）**：识别手机「无线调试 → 使用二维码配对设备」弹出的二维码，提取 IP / 配对端口 / 配对码，一键回填到「配对码连接」页。
- **🔳 生成（PC → 手机）**：本机生成配对二维码，手机扫描后由 Super_ADB 经 mDNS 自动完成 `adb pair`，无需手动输入。

**扫码（手机 → PC）**
- 支持 **从剪贴板图片** 直接扫，也支持选本地图片文件。
- 识别 `WIFI:T:ADB;S:<服务名>;P:<配对码>;;` 后解析出三要素，点 **「填入配对页」** 一键跳到「配对码连接」页回填。

**生成（PC → 手机）**
- 配对码可留空（自动随机 6 位）；服务名由 Super_ADB 自动生成（如 `superadb-AB12CD`）。
- 点 **「生成二维码并开始等待」** 后预览二维码，并自动启动 mDNS 监听（`_adb-tls-pairing._tcp`）等手机扫描；手机扫完 Super_ADB 自动发现并执行 `adb pair`。
- 生成后 **「复制」**（复制原始 payload）与 **「弹窗大图」**（独立大窗口方便手机远距离扫）启用；**「停止等待」** 可随时取消监听。

**二维码格式**

```text
WIFI:T:ADB;S:<服务名>;P:<配对码>;;
```

> ⚠️ `S` 是**服务名**而非 PC 的 IP:端口——手机用它广播自己的 mDNS 配对服务，PC 端由 Super_ADB 去发现再 `adb pair`。旧版误填 IP:端口会导致手机扫描无反应，当前版本已修正。

**常见问题**

| 现象 | 排查 |
|------|------|
| 生成后手机扫描无反应 | 手机在「使用二维码配对设备」界面；电脑与手机同网段；防火墙未拦 mDNS（5353/UDP） |
| 状态一直「等待手机扫描」 | 检查 `zeroconf` 是否正常启动（看日志） |
| 扫码识别失败 | 截图要清晰、二维码完整入镜；优先「从剪贴板图片扫码」避免二次压缩 |

## 五、综合使用流程

**场景 1：新手机首次无线调试**
1. 手机「使用配对码配对设备」弹出 IP / 端口 / 配对码。
2. 电脑「无线调试」→「配对码连接」填入 → 开始配对 → 连调试端口。

**场景 2：扫手机二维码快速回填**
1. 手机「使用二维码配对设备」显示二维码。
2. 电脑「无线调试」→「二维码连接」→「从剪贴板图片扫码」或「选择图片文件扫码」。
3. 识别后「填入配对页」自动跳到「配对码连接」回填，再开始配对。

**场景 3：生成二维码让手机扫并自动配对**
1. 电脑「无线调试」→「二维码连接」，配对码留空，点「生成二维码并开始等待」。
2. 手机「使用二维码配对设备」扫描（或点「弹窗大图」扫大图）。
3. 电脑状态变「已发现手机 … 正在执行 adb pair」，数秒后「✅ 配对成功」，设备列表刷新。

**场景 4：不知道设备 IP**
1. 电脑「无线调试」→「局域网扫描」，保持默认网段点「开始扫描」。
2. 结果里找到目标设备点「连接」。
