# 「无线调试」统一面板功能介绍

> 适用版本：Super_ADB Main 2026-08-09+
> 模块位置：`Super_ADB_Main/dialogs/wireless_debug_dialog.py`
> 子模块：`Super_ADB_Main/dialogs/lan_scanner_dialog.py`、`Super_ADB_Main/dialogs/wifi_pair_dialog.py`、`Super_ADB_Main/dialogs/qr_connect_page.py`

---

## 一、功能概览

把原来主界面「设备连接」区的两个入口——**「局域网扫描」**和**「WiFi 配对」**——合并成一个弹窗，用 `QTabWidget` 分成三个标签页：

- **局域网扫描**：自动发现同网段已开启 ADB 的设备。
- **配对码连接**：Android 11+ 无线调试的 `adb pair` 流程，输入 IP / 配对端口 / 配对码。
- **二维码连接**：扫码识别手机弹出的配对二维码并回填配对页；也可生成 PC 端二维码，手机扫描后由 Super_ADB 通过 mDNS 自动完成 `adb pair`。

这样减少主窗口按钮数量，入口更清晰；三个子页面共用一套窗口生命周期管理（关闭时统一 `cleanup()`，停掉后台扫描 / 配对 / 连接线程）。

---

## 二、入口与触发

- **位置**：主窗口「设备连接」区，原本的「局域网扫描」「WiFi 配对」两个按钮合并为 **「无线调试」** 按钮。
- **行为**：点击后弹出「无线调试」弹窗，默认停留在上一次关闭时的标签页。
- **重复点击**：窗口已开就 `raise_()` + `activateWindow()` 前置，不重复开。

弹窗顶部为一句话说明，中间是三个标签页：

### 标签页 1：局域网扫描

- 自动检测本机 IP，默认扫描同网段 `192.168.x.0/24`。
- 可自定义 IP 范围、超时、并发线程数、探测端口。
- 发现设备后可一键连接或复制 IP。
- 详细用法见 [lan-scanner-guide.md](lan-scanner-guide.md)。

### 标签页 2：配对码连接

- 输入 IP、配对端口、6 位配对码（或一键粘贴）。
- 配对成功后自动连接调试端口（默认 5555）。
- 已配对设备自动保存，可一键重连。
- 配对 / 连接历史可导出 CSV / JSON。
- 详细用法见 [wifi-pair-guide.md](wifi-pair-guide.md)。

### 标签页 3：二维码连接

集中管理扫码和生成二维码，与「配对码连接」页联动。详细用法见 [qr-connect-guide.md](qr-connect-guide.md)。

**上半部分：🔳 生成二维码（PC → 手机，扫描后自动配对）**

- 配对码可留空（自动随机生成 6 位数字）；服务名由 Super_ADB 自动生成（如 `superadb-AB12CD`）。
- 点击 **「生成二维码并开始等待」** 后，本页预览二维码（画布固定 200×200，留极小白边），并**自动启动 mDNS 监听**等待手机扫描。
- 用手机「无线调试 → 使用二维码配对设备」扫描后，手机会按服务名在局域网广播一条 `_adb-tls-pairing._tcp` 配对服务。
- Super_ADB 监听到该服务后，**自动提取手机 IP:端口并执行 `adb pair`**，无需手动输入；配对成功后主窗口设备列表自动刷新。
- 生成后 **「复制」**（复制原始 payload）与 **「弹窗大图」**（独立大窗口，方便手机相机远距离扫描）按钮启用；**「停止等待」** 可随时取消 mDNS 监听。
- 状态行实时显示「等待手机扫描 / 已发现手机 / 配对成功或失败」。

**下半部分：📷 扫描二维码（手机 → PC）**

- 支持从**剪贴板图片**直接扫码，也支持选择本地图片文件。
- 识别到 `WIFI:T:ADB;S:<服务名>;P:<配对码>;;` 格式后，解析出手机的 IP / 端口 / 配对码。
- 点击 **「填入配对页」**（与两个扫码按钮同一行）一键切到「配对码连接」页并回填字段，再点「开始配对」即可。

二维码格式（注意 `S` 是**服务名**而非 IP:端口）：

```text
WIFI:T:ADB;S:<服务名>;P:<配对码>;;
```

> ⚠️ 常见误区：旧版曾把 `S` 写成 PC 的 `IP:端口`，导致手机扫描后毫无反应——因为手机需要的是「服务名」来广播自己的 mDNS 配对服务，而 PC 端必须由 Super_ADB 去发现该服务再 `adb pair`。当前版本已修正此问题。

## 四、典型使用流程

### 场景 1：新手机首次无线调试

1. 手机：设置 → 开发者选项 → 无线调试 →「使用配对码配对设备」。
2. 电脑：主窗口点 **「无线调试」** → 切到 **「配对码连接」** 页。
3. 填入手机弹窗中的 IP、配对端口、配对码 → 点「开始配对」。
4. 配对成功后点「连接调试端口」（默认 5555），主窗口设备列表自动刷新。

### 场景 2：快速回填手机上的配对二维码

1. 手机：进入「无线调试 → 使用二维码配对设备」，屏幕显示二维码。
2. 电脑：点 **「无线调试」** → 切到 **「二维码连接」** 页 →「从剪贴板图片扫码」或「选择图片文件扫码」。
3. 识别成功后点「填入配对页」，自动跳到「配对码连接」页并填好字段。
4. 返回步骤 1 的流程点「开始配对」。

### 场景 3：生成二维码让手机扫描并自动配对

1. 电脑：主窗口点 **「无线调试」** → 切到 **「二维码连接」** 页。
2. 配对码可留空（自动随机生成 6 位），点 **「生成二维码并开始等待」**。
3. 手机：进入「无线调试 → 使用二维码配对设备」，扫描电脑上弹出的二维码（或点「弹窗大图」后的大图）。
4. 电脑端状态行变为「已发现手机 … 正在执行 adb pair」，数秒后提示「✅ 配对成功」，主窗口设备列表自动刷新。

### 场景 4：不知道设备 IP

1. 主窗口点 **「无线调试」** → 切到 **「局域网扫描」** 页。
2. 保持默认网段，点「开始扫描」。
3. 在结果里找到目标设备，点「连接」。

## 五、注意事项

- 嵌入子对话框/子页面后，其 `closeEvent` 不会单独触发；关闭「无线调试」弹窗时会统一调用各子页面的 `cleanup()`，停掉后台扫描 / 配对 / 连接线程，避免悬挂。
- 配对端口（如 `38973`）是一次性的，配对完成后要立即连接调试端口；等待过久会过期。
- 历史记录与已配对设备分别保存在 `wifi_debug_history.json` 和 `wifi_paired_devices.json`（项目配置目录）。
- 二维码生成依赖 `segno`（纯 Python，无额外 C 依赖），已写入 `requirements.txt`；冻结构建已同步加入 `--hidden-import segno`。
- 生成二维码的自动配对依赖 `zeroconf`（mDNS 监听 `_adb-tls-pairing._tcp`），同样已写入 `requirements.txt` 并加入 `--hidden-import zeroconf,ifaddr`。
