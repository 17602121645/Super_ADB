# 时间戳转换 — 功能介绍

> 适用版本：Super_ADB 主窗口 → **便捷工具 → 「时间戳转换」按钮**
> 代码文件：`Super_ADB_Main/timestamp_dialog.py`（~170 行，独立弹窗）
> 入口：`main_window.timestampBtn.clicked → open_timestamp()`（主窗口 `Super_ADB_Main.py:235` 连接 / `:979` 实现）
> 复用策略：QDialog 弹窗 + 单例 raise，不阻塞主窗口

---

## 1. 功能概览

一个**纯本地**的时间戳 ↔ 北京时间 双向转换弹窗——零网络、零 ADB、零依赖：

| 能力 | 操作 |
|---|---|
| **时间戳 → 北京时间** | 输入 Unix 时间戳，自动识别 秒 / 毫秒 / 微秒 / 纳秒，实时显示北京时间 |
| **北京时间 → 时间戳** | 用日期时间选择器选北京时间，实时给出 Unix 秒级 + 毫秒级 |
| **一键复制** | 每个结果框右侧「复制」按钮 → 复制到剪贴板 |

**跟 MD5 / JSON 工具同一类定位**——内嵌小工具箱里的轻量工具。特点：
- 实时转换（输入即出，无需点「转换」按钮）
- 北京时间固定按 UTC+8 计算，结果不受机器时区影响
- 支持任意位数时间戳（10 位秒 / 13 位毫秒 / 16 位微秒 / 19 位纳秒）

## 2. 入口与触发

主窗口 → **便捷工具 → 「时间戳转换」按钮**。

按钮的 tooltip：
> Unix 时间戳 ↔ 北京时间 互转

点击行为（`Super_ADB_Main.py:979-987`）：

```python
def open_timestamp(self):
    """打开时间戳转换弹窗（复用窗口，重复点击 raise）。"""
    if self._timestamp_dialog is not None and self._timestamp_dialog.isVisible():
        self._timestamp_dialog.raise_()
        self._timestamp_dialog.activateWindow()
        return
    self._timestamp_dialog = TimestampDialog(parent=self)
    self._timestamp_dialog.show()
```

跟 `open_md5()` / `open_json_tool()` 完全相同的**复用窗口模式**——重复点击只是 `raise_()` 置顶，不创建新实例。

操作：日期选择器选 2026-01-01 00:00:00.000 → 毫秒级 = 1767225600000
```

```

## 5. 技术细节

### 时间戳位数识别

内部 `_norm_ts()` 函数按数字长度自动归一到秒级浮点：

| 位数 | 含义 | 归一方式 |
|---|---|---|
| ≤ 10 | 秒 | 直接使用 |
| ≤ 13 | 毫秒 | ÷ 1000 |
| ≤ 16 | 微秒 | ÷ 1,000,000 |
| > 16 | 纳秒 | ÷ 1,000,000,000 |

### 时区处理

- 北京时间定义为 `BJ = timezone(timedelta(hours=8))`
- **时间戳 → 北京时间**：先转为 UTC datetime，再 `.astimezone(BJ)` 得北京时间
- **北京时间 → 时间戳**：本地 naive datetime 加上 `tzinfo=BJ` 后调用 `.timestamp()`
- 结果与用户本机时区无关（即使机器设为 UTC-5，北京时间仍然是 UTC+8）

### 实时响应

- 时间戳输入框绑定 `textChanged` 信号 → 每次按键立即更新结果
- 日期时间选择器绑定 `dateTimeChanged` 信号 → 选择变化立即更新结果
- 无需额外「转换」按钮

## 6. 常见问题

**Q：为什么我的北京时间看起来不对？**
A：日期时间选择器读取的是你机器的本地时间。如果机器时区不是 UTC+8，选出来的"北京时间"会偏移。中国用户通常没问题——Windows 默认时区就是北京时区。

**Q：支持负数时间戳吗？**
A：支持。`_norm_ts()` 对绝对值做长度判断，所以 `-1754654325` 也能正确转换为 1964 年的北京时间（1970 年之前）。

**Q：能同时批量转换多个时间戳吗？**
A：目前是单条实时转换。如果需要批量，可以逐个输入复制；后续可考虑加「批量模式」（每行一个时间戳，一次性全部转换）。
