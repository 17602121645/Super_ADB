📊 项目概览

基于 PySide6 的 Android ADB 桌面工具集，支持设备管理、文件传输、性能监控、证书安装、WiFi 调试等功能。

技术栈

Python 3.14 PySide6 (Qt6) ADB 协议 (自研) RSA2048 认证 QSS 主题系统 (7套) 无边框自定义窗口 多线程 (QThreadPool) PyInstaller 打包 自研ADB协议栈 (纯Python) openh264 投屏解码 scrcpy 投屏 OpenGL 渲染 cryptography pyusb (USB通道) 三种ADB模式切换

主题切换流程：_切换主题 → setStyleSheet → 刷新标题栏按钮 → 延迟 _强制主题重绘 → 同步打开中的弹窗样式。

弹窗样式跟随主题（正确做法）

# 1. 创建弹窗：只给对话框 setStyleSheet，子控件不单独设样式
dlg = QDialog(self)
dlg.setStyleSheet(get_stylesheet(self._current_theme))
# QLabel / QTextEdit 等子控件自动继承全局主题样式，不要 setStyleSheet

# 2. 主题切换时同步更新打开的弹窗（在 _切换主题 中）
if hasattr(self, '_设备信息弹窗') and self._设备信息弹窗 is not None:
    self._设备信息弹窗.setStyleSheet(get_stylesheet(theme_id))

# ❌ 错误：子控件写死颜色，切换主题后不变
label.setStyleSheet('color:#58a6ff;background:#0d1117')
edit.setStyleSheet('QTextEdit{background:#0d1117;color:#e6edf3}')

📖 模块详解

核心模块的功能说明和关键接口。

入口层

Super_ADB_主入口.py — 主窗口

主窗口类，继承 QWidget + Ui_MainWindow + 3个 Mixin。负责窗口初始化、信号连接、ADB 实例管理、线程池、配置持久化。

关键属性：self.adb(Adb设备操作)、self.pool(QThreadPool)、self._current_theme、self._live_workers

主入口_弹窗打开.py

Mixin 14个 open_xxx 方法，创建并显示对话框/窗口，支持实例复用（重复点击 raise）。

主入口_设备管理.py

Mixin 设备连接/断开/扫描，当前序列号() 获取当前选中设备序列号。

主入口_主题系统.py

Mixin 7套主题切换、标题栏按钮样式、品牌标识、弹窗主题传播。

UI 层

对话框基类.py

基类 统一对话框图标、样式、发光效果、主题切换。参数：标题/最小尺寸/发光。

界面样式.py

🏗️ 架构机制

线程模型、单实例、窗口持久化、日志系统等核心机制。

🔀 三种ADB模式

系统adb：调用PATH中的adb.exe，最稳定。Socket直连：直连127.0.0.1:5037，不启动adb进程。自研ADB：纯Python实现ADB协议，直连设备5555端口，无需官方adb。

🧵 线程模型

命令工作器(QRunnable) + QThreadPool 异步执行 ADB 命令，避免阻塞 UI。结果通过 工作器信号 信号回传（result/error/finished）。长任务用 QThread（如安装线程、哈希线程）。

🔒 单实例机制

单实例(QObject) 通过系统互斥量（mutex）防止多开。第二个实例启动时检测到已有实例，自动退出并激活已有窗口。

📐 窗口几何持久化

启动时从配置读取 geometry.b64（saveGeometry 的 base64 编码），调用 restoreGeometry() 恢复窗口位置/大小/状态。关闭时 saveGeometry() 写入配置。

📝 日志输出系统

三级输出：日志() 输出框（主窗口文本区）、设置状态() 状态栏（底部提示，带成功/失败颜色）、日志查看器页（logcat 实时流）。

🔑 自研ADB认证与密钥管理

密钥 super_adb_key(+.pub) 源码模式在 配置/，打包版在 exe 旁 配置/（首次访问自动从旧位置/源码树迁移）。认证失败后 30 秒负缓存冷却；发公钥后 60 秒循环等待设备授权（盒子/TV 等无授权弹窗的 ROM 会断开连接，错误消息提示复制已授权密钥）。

🎬 投屏 H.264 解码链路

scrcpy-server 推送 H.264 NAL → h264解码器（ctypes 调 openh264 DLL）→ YUV → OpenGL 纹理上屏。解码线程与渲染线程解耦，停屏时快速退出并释放解码器。

🔗 连接池架构

自研ADB采用设备级建连锁 + 连接池。短操作（shell命令）共享主连接加锁串行；长操作（推送/拉取/安装）用独立连接。后台daemon线程清理空闲连接。

注意事项

⚠️ 循环导入：Mixin 文件中如需导入主入口的类（如 命令工作器），必须在方法内部延迟导入，不能在文件顶部导入。
⚠️ UI 定义分离：新增按钮/控件必须在 .ui 文件中定义，编译后代码只做样式和信号连接。不要在代码中动态创建 UI 控件。
⚠️ 中文命名：新建文件/类/方法/变量一律使用中文命名。历史英文代码保持不变，重构时逐步迁移。
⚠️ 包式导入：所有 import 使用包名前缀（from 对话框.xxx import ...），不要使用裸导入。sys.path 只加 Super_ADB_Win/ 根目录。
⚠️ 线程安全：ADB 命令必须异步执行（QThreadPool + QRunnable），不能在主线程直接调用。结果通过信号回传。
⚠️ 主题传播：自定义对话框必须实现 apply_theme(theme_id) 方法，主题切换时会自动调用。无边框对话框需手动同步样式。
⚠️ 弹窗控件样式勿写死：弹窗内的 QLabel / QTextEdit / QPushButton 等子控件不要单独调用 setStyleSheet 写死颜色（如 color:#58a6ff;background:#0d1117），否则会覆盖全局主题，切换主题后控件样式不变。正确做法：只给对话框本身 setStyleSheet(get_stylesheet(theme_id))，子控件自动继承全局样式（界面样式.py 已定义 QTextEdit/QLabel/QPushButton 等主题样式）。若必须自定义，用 THEMES[theme_id] 取色并在主题切换时重新 apply。弹窗打开状态下切主题：在 _切换主题 中检查 self._xxx弹窗 是否存在，存在则调用 setStyleSheet(get_stylesheet(新主题))。参考：设备信息弹窗实现。
⚠️ 实例复用：弹窗打开方法必须检查实例是否已存在且可见，重复点击应 raise 而非新建。关闭后通过 destroyed 信号清空引用。
⚠️ 设备序列号：对话框标题应包含设备信息（xxx — 设备: {serial}），通过 get_serial() 回调获取，未连接时显示「未连接设备」。
