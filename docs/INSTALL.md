# 安装说明

## 下载

前往 [GitHub Releases](https://github.com/17602121645/Super_ADB/releases) 下载对应平台的安装包：

| 平台 | 安装包 |
|------|--------|
| Windows | `Super_ADB_Win.zip` |
| macOS | `Super_ADB_mac.zip` |

## 安装

找个盘解压就行，解压后直接运行即可，无需额外安装。
