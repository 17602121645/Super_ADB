## 生成项目全景文档.py — 新增「对话框模拟运行截图」章节

- 需求：基于 `对话框/` 目录自动离屏渲染每个弹窗，截图嵌入 HTML 全景文档，配功能介绍与使用方法。
- 实现：
  - 用 `ast` 定位每个文件的主弹窗类（与文件同名优先，类名关键词：对话框/窗口/页/菜单/Dialog/Window/Page），`importlib` 动态加载。
  - `inspect.signature` + 智能参数映射（_ADB桩 / _主窗口桩 / QThreadPool / 假序列号 / lambda 回调）解决 22 个不同构造签名的弹窗。
  - `QT_QPA_PLATFORM=offscreen` + `dlg.show() / processEvents / grab()` 抓屏，合成到带 14px 边距的深色画布（适配无边框半透明弹窗）。
  - 模块 docstring 自动解析为「功能介绍」+ 提取含操作动词的句子作为「使用方法」+ 源码正则提取「主要操作」按钮文字。
  - HTML 新增 `<h2 id="dialog-screenshots">` 章节，22 个 feature-block 网格，失败对话框汇总在 warn-box。
  - 导航栏加链接；支持 `--跳过截图` / `--skip-shots` 跳过加速。
- 顺手修复：原脚本所有 `read_text(encoding='utf-8')` 改 `utf-8-sig`，解决 9 个带 UTF-8 BOM 的对话框文件被 `ast.parse` / 类扫描静默跳过（含 `scan_classes` 中也有同样隐患）。
