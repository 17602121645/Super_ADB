## 修复主窗口标题不生效问题
- 现象：在 `Super_ADB.ui` 把 windowTitle 改成 Super_ADB 后，运行仍显示旧标题 "ADB Shell 快捷命令工具"。
- 根因：`Super_ADB_Main/main.py` 的 MainWindow.__init__ 在 setupUi() 之后硬编码了 `self.setWindowTitle('ADB Shell 快捷命令工具')`，覆盖了 .ui 文件设的标题，属于 UI 与逻辑分离不彻底。
- 修复：删除 main.py 中该行硬覆盖，标题交由 .ui 文件管理。
- 结论：本项目 UI 架构为 .ui + pyside6-uic 生成 Super_ADB.py + main.py 多重继承，修改窗口标题只需改 .ui 的 windowTitle，不要再在 main.py 覆盖。
